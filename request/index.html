利用許諾（標準）

納品した動画を、ご自身のチャンネル・SNS・広告・社内で、期間の定めなく使えます。収益化もできます。著作権は CADENCE に残り、制作実績として紹介することがあります（紹介しない指定もできます）。

著作権の譲渡（追加料金・応相談）

動画の著作権（著作権法 27 条・28 条の権利を含む）をお渡しし、著作者人格権は行使しません。目安は基本料金の +50% 【本人が決める: 割合】。台本・設定画などの途中の素材も含めるかは、ご相談で決めます。

どちらの場合も、お預かりした素材はお客様のものです。こちらで用意する合成音声（VOICEVOX ほか）・音楽・効果音は、それぞれの規約の範囲でのご利用になります（クレジット表記が要るもの、YouTube の Content ID に登録できないものはお伝えします）。AI で生成した絵の部分には、法律上の著作権が生じない場合があります。
