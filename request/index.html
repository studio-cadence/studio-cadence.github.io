著作権

利用許諾（標準）

納品した動画は、ご自身のチャンネル・SNS・広告・社内で、期間や媒体の制限なくお使いいただけます。収益化や、字幕の追加・切り出しなどの手直しも自由です。著作権は CADENCE に残ります。制作実績として紹介することがあります（紹介しない指定もできます）。

著作権の譲渡（ご希望の場合・追加料金）

お見積もりの前にお申し付けください。動画の著作権（著作権法 27 条・28 条の権利を含む）をお渡しし、著作者人格権は行使しません。追加の料金は、内容をうかがってお見積もりします。

元の素材

標準の納品物は、完成した動画とクレジットです。台本・絵の元データ・編集のプロジェクトファイルが必要な場合は、追加料金でお渡しします（有料素材など、規約でお渡しできないものを除きます）。

どちらの場合も、お預かりした素材はお客様のものです。こちらで用意する合成音声（VOICEVOX ほか）・音楽・効果音は、それぞれの規約の範囲でのご利用になります（クレジット表記が要るもの、YouTube の Content ID に登録できないものはお伝えします）。AI で生成した絵の部分には、法律上の著作権が生じない場合があります。
